# 3D Portfolio Scene with Interactive Car

A 3D interactive portfolio built with **Three.js**, featuring a cozy, atmospheric room scene and an interactable toy car that can move around to trigger different portfolio interactions. The project is designed to combine Blender-modeled assets with Three.js-powered interactivity.

## Introduction
This project is part of a larger personal portfolio experience inspired by the "digital bedroom" concept. The user can explore the 3D scene and interact with different objects — starting with a movable toy car that will be able to roam the environment and activate hotspots (e.g., downloading a CV, accessing project showcases, toggling scene elements).
